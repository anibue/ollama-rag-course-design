# 人工智能与 RAG 技术资料

## Transformer

Transformer 是一种基于注意力机制的神经网络架构。它不依赖循环结构，而是通过自注意力计算序列中不同位置之间的关联。多头注意力可以在多个表示子空间中学习不同关系，位置编码用于补充词序信息。Transformer 的并行计算能力强，已经成为大语言模型、机器翻译和文本生成任务的重要基础。

## 大语言模型本地部署

Ollama 可以在本地管理和运行大语言模型。用户通过 ollama pull 拉取模型，通过 ollama run 进行交互式推理，也可以通过本地 HTTP API 调用模型。课程设计中采用本地部署的好处是数据不需要上传到第三方服务，便于保护专业文档隐私，也方便复现实验环境。

## Embedding 与语义检索

Embedding 模型把文本映射为高维向量，使语义相近的文本在向量空间中距离更近。RAG 系统通常先把文档切分成片段，再为每个片段生成向量。用户提问时，系统把问题也转为向量，并使用余弦相似度检索最相关的片段。检索结果会作为上下文交给生成模型。

## RAG 流程

RAG 是 Retrieval-Augmented Generation 的缩写，即检索增强生成。它把外部知识库检索与大模型生成结合起来。基本流程是文档解析、文本切分、向量化入库、问题向量化、相似度检索、Prompt 拼接和答案生成。RAG 可以缓解大模型知识过时、专业知识不足和幻觉问题，但检索质量、切分策略和提示词约束会直接影响最终效果。

## Prompt 约束

专业文档问答场景需要明确要求模型依据资料回答。当检索片段中没有答案时，模型应拒绝编造并说明知识库没有找到明确答案。Prompt 中还可以要求模型给出引用来源、分点解释和不确定性说明，从而提升答案可追溯性。
