Module Legend

模块说明

数据准备层 collect_public_kb.py 负责采集公开资料，data/ 与 data/public_kb/ 提供知识源。
索引构建层 build_kb.py 负责文档读取、切块、向量化，并生成本地索引文件。
RAG 核心层 rag_chain.py 统一实现检索、去重、上下文扩展、生成和忠实度检查。
交互入口层 app.py 提供可视化问答界面，CLI 直接调用核心问答逻辑。
评测实验层 eval.py、model_compare.py、prompt_compare.py 等脚本复用核心模块做实验。
结果输出层 所有批量实验结果统一落在 results/ 目录，便于写报告和做对照分析。
